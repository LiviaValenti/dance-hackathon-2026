# Pitch deck: "La oss danse"

A copy of the hackathon pitch deck (2-minute pitch, in Norwegian), exported on 2026-11-12. The live, editable deck is a Claude Slides artifact: https://claude.ai/artifact/8SMgEAFvUtukNGyFtFb8LE (ask the owner for access). Edit it there; this folder is a snapshot and does not sync back.

- `index.html`: all slides on one page, for a quick look in a browser. A static preview: no click builds (the last slide shows all its phrases at once) and no speaker notes.
- `slides/`: one file per slide, numbered in deck order. Each `<aside>` holds the speaker notes with the Norwegian script and `[KLIKK]` cues.
- `deck.json`: slide order, sections and fonts (Archivo for headings, Inter for text).
- `assets/dancing.gif`: the animation on slide 4.

The decisions, sources and Q&A answers behind the pitch are in [../pitch.md](../pitch.md).
